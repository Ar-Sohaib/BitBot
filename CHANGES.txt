RÉSUMÉ DES CHANGEMENTS
================================================================================

AVANT
─────
- Messages logs-like [PAPER][BTC] Tag — hard à lire
- Pas de rate limiting → inondation possible (ex: startup à chaque restart)
- Pas de state tracking → doublons feed down/ok
- Formatage inline dans les méthodes

APRÈS
─────
✅ 8 templates Markdown ergonomiques (emojis, gras, monospace)
✅ Rate limiting (startup 1/6h, feed transition, wallet 1/h, report 1/day)
✅ Idempotence (trade_id, state keys)
✅ Code modulaire (format vs dispatch séparé)
✅ Anti-spam via dispatcher


================================================================================
8 TEMPLATES IMPLÉMENTÉS
================================================================================

1️⃣  🟢 STARTUP — Bot démarrage (rate limit 1/6h)
2️⃣  ✅ TRADE_BUY — Achat paper (idempotent trade_id)
3️⃣  ✅ TRADE_SELL — Vente + PnL (idempotent trade_id)
4️⃣  🔴 KILL_SWITCH — Drawdown stop (aucun rate limit)
5️⃣  ⚠️  FEED_DOWN — Feed timeout (transition only)
6️⃣  🟢 FEED_OK — Feed rétabli + durée (transition only)
7️⃣  📊 DAILY_REPORT — Rapport jour (rate limit 1/day)
8️⃣  🟠 WALLET_LOW — Cash faible (rate limit 1/h)


================================================================================
DISPATCHER ANTI-SPAM
================================================================================

Classe: TelegramDispatcher
Responsabilité: Checks + state persistance

Méthodes:
  should_send_startup()          → bool
  mark_startup_sent()            → None
  should_send_feed_down()        → bool
  mark_feed_down()               → None
  should_send_feed_ok()          → bool
  mark_feed_ok()                 → None
  get_feed_downtime_seconds()    → int
  should_send_wallet_low()       → bool
  mark_wallet_low_sent()         → None
  should_send_daily_report(date) → bool
  mark_daily_report_sent(date)   → None
  should_send_trade(trade_id)    → bool
  mark_trade_sent(trade_id)      → None

État Persisté:
  last_startup_notif_ts          (epoch float)
  feed_status                    ("ok" / "down")
  feed_down_since_ts             (epoch ms)
  last_wallet_low_notif_ts       (epoch float)
  last_daily_report_date         (YYYY-MM-DD)
  trade_notif_{id}               ("1")
